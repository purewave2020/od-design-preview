# Lumen 3.0 — design notes

This folder is the **demo project** bundled with *Open Design Preview*. Open any
file from the **Design Files** tab to see the matching viewer.

![Hero artwork](../assets/hero.jpg)

## What's inside

| File | Viewer | Try |
| --- | --- | --- |
| [`index.html`](../index.html) | HTML preview | Desktop / Tablet / Mobile viewports, zoom, Present |
| [`product-slides.html`](../product-slides.html) | Deck | ← → keys, thumbnail rail, speaker notes |
| [`pitch-deck.html`](../pitch-deck.html) | Deck | Upstream `html-ppt-pitch-deck` example |
| [`mobile/onboarding.html`](../mobile/onboarding.html) | HTML preview | Switch to the Mobile viewport |
| [`dashboard.html`](../dashboard.html) | HTML preview | Upstream `dashboard` example |
| [`tokens.json`](../tokens.json) | Code | Pretty-printed JSON with line numbers |
